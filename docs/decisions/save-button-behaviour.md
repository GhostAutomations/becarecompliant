# Save button behaviour

> CURRENT RULE: "Saving…" the instant it is pressed, then green "Saved" (or "Sent" for send buttons, which say "Sending…" while working) that STAYS until the section is edited again; no timer. See "CURRENT AUTHORITATIVE RULE" below. The "HARD RULE" and "How to apply" blocks further down describe the old 2 second flash and are superseded; they are kept for history only.

Before creating ANY new save/send button, follow that doc.

### ROOT CAUSE of "why is the button a green RECTANGLE" (found 2026-07-21): `.btn-saved` was NOT listed in the shared base-button grouped selector in app/globals.css (`.btn, .btn-primary, .btn-danger, .btn-ghost, .btn-outline { @apply inline-flex ... rounded-xl px-4 py-2.5 ... }`). So when a button swapped its class to `btn-saved` it LOST all button shape (padding/radius/inline-flex/font) and rendered as a bare coloured rectangle. FIX: added `.btn-saved` to that base group so it keeps identical button shape, and set its fill to solid green (`bg-rag-green text-white shadow-sm`). This is THE fix for the rectangle across the whole app. If a "saved" state ever looks like a bare rectangle again, check it is still in the base group.

**How to apply:** `ActionForm` uses a transient `saved` state cleared by a `setTimeout` (2s) and reset on any `onChange`. For bespoke save buttons (not using ActionForm) use the shared hook `lib/use-saved-flash.ts` → `const [saved, flash, reset] = useSavedFlash();` call `flash()` on success, `reset()` on edit, className `saved ? "btn-saved" : ...`. Audited + fixed all 12 bespoke buttons on 2026-07-16 (edit-person, edit-service-user, edit-complaint, team-member-controls, branch-form, absence-settings, absence-detail-dialog, check-config, probation-period, column-names, su-column-names, complex-interval). NOTE: the complaint "done" status buttons (initial-response, complaint-response, complaint-forms `f.done`) are INTENTIONALLY persistent green — they are done-indicators Phil asked for, not save buttons; leave them. Route new save UIs through `ActionForm` or `useSavedFlash`, never a sticky success colour. See [brand-decisions](brand-decisions.md).
