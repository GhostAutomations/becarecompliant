# Phase8 decisions

> BCC Phase 8 (Reporting, exports & audit trail) agreed scope decisions, popup 2026-07-13

Phase 8 = Reporting, exports & audit trail. Two pillars. Scope agreed by Phil (single planning popup, 2026-07-13):

- **Report set = all four**, in a new **/reports** area PLUS contextual Export buttons on registers + record drill-downs: (1) register report, (2) branch/company compliance report, (3) per-record Evidence pack (PDF + CSV index), (4) audit-trail report. ALL routed through ONE shared module `lib/export/*` (a @react-pdf/renderer PDF helper + a single CSV helper, no new dependency, no ad-hoc CSV string building). Reuse renderEvidencePdf + the 5-minute signed-URL TTL (SIGNED_URL_TTL_SECONDS=300).
- **Tier gating:** exports = Pro+ via requireFeature("reporting_exports") server-side. **EXCEPTION Phil chose: Business tier CAN download a single record's own Evidence PDF** (one at a time, audit-logged). Packs, register/branch and audit-trail exports stay Pro+. Business sees a clear upgrade state on the Pro+ export buttons.
- **Audit depth = LEAN (Phil's exact words "action date time name of user"):** capture action (dotted verb), actor name/email/role, timestamp, entity, summary line. **NO old->new value diffs, NO IP capture.** This overrides the brief's "old->new where it matters". audit_log columns already suffice; likely no migration for audit itself. Retention left unbounded.
- **Probation extension in reports = show all four fields:** Original end due, Extension date, Actual end, Status (from person_trackers: probation_end_due, probation_extension_date, probation_end_actual, probation_status enum passed/failed/extended/due). Full history visible to inspectors.
- **GDPR read-audit scope (Claude default, Phil can override):** log every Evidence view/download + every Service User record open (special-category). Do NOT log every People record open (not special-category, would flood the log). service_user.viewed already wired at app/(app)/service-users/[id]/page.tsx; signEvidenceDownload already writes evidence.downloaded but is not yet called by any UI (Phase 8 wires it).
