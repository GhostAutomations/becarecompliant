**Original scope (Phil's choices 2a/3a/4a still hold):**
- (SUPERSEDED by model change above) Private Client = own payer record (person OR organisation), optional link to a Service User. Branch scoped, transferable.
- v1 = create/send/track invoices, NO Stripe card payments (pay-by-link is a later slice). Mark paid in full manually (date + method); partial payments later.
- Amounts = line items ("Line", never "item") + optional recurring weekly/monthly schedule that auto-drafts.
- VAT off by default (welfare exemption). Tick VAT in Settings→Invoicing REQUIRES a VAT number (DB CHECK); no number = no VAT.
- Numbering: prefix editable by Admin; start number system-controlled (founder-only editable), gapless, allocated on Send by SECURITY DEFINER RPC `invoicing_send_invoice`.
- Bank/payment details entered in Settings→Invoicing, shown on every invoice (BACS, since no Stripe v1).
- Overdue email reminders with a company on/off toggle in Settings→Invoicing.
- Visibility = Branch Manager and above (is_platform_admin/is_company_admin/is_branch_manager), like Complaints. No Supervisor/Team Member/Viewer.

**Terminology (confirmed):** Invoicing, Private Client, Invoice, Line, Rate list. Statuses Draft/Sent/Paid/Void; Overdue is DERIVED (sent + due<today + unpaid), never stored.
