# Test checklist: the review's Outcomes section (2026-10-05)

Bevan first, then Thistle.

- O1 Review number is not shown on the review, from the record's Review box or from any other link; the heading says which review it is.
- O2 Customer Satisfaction ends with care worker feedback (not scored), then improve this service and further comments.
- O3 Review of Personal Plan ends with "Were any other individuals present?" and "Who?".
- O4 Outcomes section lists the person's active outcomes from their Outcomes page, two answers each, then "Would you like to set a new outcome?".
- O5 A person with no outcomes is asked to set one, and the review cannot be submitted without it.
- O6 Submitting logs each outcome's update on the Outcomes page with the note; Achieved moves it to Achieved; the new outcome appears with its target date.
- O7 Submitting the same review twice does not log the updates or create the outcome twice.
- O8 The Evidence and PDF show the Outcomes section in words.
